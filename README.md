## 🚀 Featured Projects

### 1. Name That LLM — Machine Learning Classification

A machine learning project exploring how text characteristics can help identify which Large Language Model generated a text sample.

**Key work**

* Compared multiple classification algorithms.
* Evaluated character-level and word-level TF-IDF features.
* Engineered numerical text-statistics features.
* Used grouped validation based on prompt IDs.
* Compared model performance across three validation splits.

**Best recorded local validation result:** 31.42% mean balanced accuracy.

[Explore the project on GitHub](https://github.com/william-lazer/name-that-llm-classification)
